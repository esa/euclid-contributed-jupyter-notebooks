# Euclid Contributed Jupyter Notebooks

Community-contributed Jupyter notebooks for the data releases of the **ESA Euclid mission**, curated by the **Euclid Data Space User Group**.

These notebooks complement the ESA-developed Euclid notebooks by providing additional science examples, analysis workflows and demonstrations of tools that can be used with Euclid data.

## About these notebooks

The notebooks in this repository are contributed by members of the Euclid community.They may demonstrate:

- scientific analysis of Euclid data;
- access to Euclid catalogues, images and spectra;
- visualisation and exploration of Euclid data products;
- use of community-developed astronomy software;
- workflows combining Euclid data with external datasets or services.

The notebooks are intended to provide practical examples that users can adapt for their own scientific analysis.

## Running the notebooks on Euclid Data Space

The recommended environment for running these notebooks is the **Euclid app** on ESA Datalabs.

The Euclid app provides a JupyterLab environment with the main Euclid and scientific Python packages installed and direct access to the public Euclid data volumes.
